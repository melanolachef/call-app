# Novidades do app para Windows

Cada versão tem uma seção `## X.Y.Z`, a mais nova em cima. Ao publicar a tag
`app-vX.Y.Z`, o workflow põe a seção dessa versão no texto do release (e o
aviso de instalação no fim). Escreva para quem usa o app, sem termos técnicos.

## 0.3.0

- O app agora se atualiza sozinho: quando sair uma versão nova, aparece o aviso **Nova versão do app · Reiniciar e atualizar**. Esta versão ainda precisa ser instalada à mão.
- Abrir uma foto do chat ou um link não tira mais você da call.
- Apoiar (Pix) e os links de fora abrem no navegador.
- **Ctrl+Shift+D** liga e desliga o fone (o **Ctrl+Shift+M** continua mutando o microfone), com o jogo em foco.
